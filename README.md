# Customer Segmentation using K-Means Clustering

## 📌 Project Overview

This project uses K-Means Clustering to segment customers based on their annual income and spending behavior.

## 🎯 Objective

Identify different groups of customers so businesses can create targeted marketing strategies.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Google Colab

## 🤖 Algorithm

K-Means Clustering

## 📊 Features

- Annual Income
- Spending Score

## 🔄 Workflow

Dataset
↓
Data Preprocessing
↓
Feature Scaling
↓
Elbow Method
↓
K-Means Clustering
↓
Customer Segmentation
↓
2D Visualization
↓
New Customer Prediction

## 👥 Customer Segments

- High Income - High Spending
- High Income - Low Spending
- Low Income - High Spending
- Low Income - Low Spending

## 📈 Visualization

The project visualizes customer clusters using 2D scatter plots.

## ▶️ How to Run

1. Download the repository.
2. Open `customer_segmentation_kmeans.ipynb`.
3. Upload it to Google Colab.
4. Run all cells.
5. Enter income and spending score for a new customer.
6. View the predicted customer segment.
